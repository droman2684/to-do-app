# Project: Ultra-Simple Notebook To-Do App

## Overview
Build a highly minimalist web-based To-Do list application. The strict primary directive is simplicity. The UI must mimic a physical lined notebook. 

## UI/UX Design
* **Aesthetic:** The main interface must look like a piece of lined notebook paper (e.g., a background with repeating horizontal blue lines, and potentially a vertical red margin line).
* **Alignment:** The text input, checkboxes, and dropdowns must align perfectly so that each task sits naturally on a single printed line of the notebook.

## Core Features
1.  **Task Entry:** Users can type a new task onto a line.
2.  **Task Completion:** A simple checkbox next to each task to mark it as done (applying a visual strikethrough to the text when checked).
3.  **Categories:** * A simple dropdown menu next to each task to assign it to a category.
    * The ability to easily add new categories to this dropdown list.
4.  **Filtering & Sorting:**
    * A global control at the top of the page to filter the visible lines by a specific category.
    * A basic sort function to group the current list of tasks by their category.

## Strict Constraints (Do NOT Include)
* **NO** priority levels or flags.
* **NO** due dates, times, or calendars.
* **NO** sub-tasks, nesting, or complex project folders.
* **NO** bulky UI frameworks that ruin the simple notebook illusion. Keep the HTML, CSS, and JavaScript as clean and lightweight as possible.
